## Framework boundary

The pack applies only when users or counterparties create incremental value
for other users through a defined interaction. It does not treat:

- virality alone,
- a large customer base,
- data volume alone,
- brand,
- economies of scale, or
- generic retention

as proof of a network effect.

Local, workplace, marketplace, social, gaming, developer, and data networks
require different atomic units and metrics. New geographies or segments may
reset the cold-start problem.
