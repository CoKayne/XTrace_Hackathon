# Atomic Claims — Andrew Chen / The Cold Start Problem

### CSP-CLM-001
A network effect exists when incremental participation increases product or
service value for other participants through a defined interaction.

### CSP-CLM-002
Virality is an acquisition mechanism and can exist without a network effect;
the two must be measured separately.

### CSP-CLM-003
More data alone does not create a network effect unless data changes
participant interactions or produces a defensible feedback mechanism.

### CSP-CLM-004
The Cold Start framework has five stages: Cold Start, Tipping Point, Escape
Velocity, Ceiling, and Moat, with different questions at each stage.

### CSP-CLM-005
An atomic network is the smallest stable network that provides recurring
value and can serve as a unit for replication.

### CSP-CLM-006
Atomic-network boundaries depend on product context such as city, school,
team, workplace, game instance, buyer/seller market, or other interaction unit.

### CSP-CLM-007
The hard side is the minority of participants who contribute disproportionate
network value and are correspondingly harder to acquire and retain.

### CSP-CLM-008
A cold-start strategy must solve a sufficiently important problem for the hard
side rather than only attracting the easier side.

### CSP-CLM-009
The cold-start problem is solved repeatedly as a company enters new networks,
segments, cities, teams, or geographies.

### CSP-CLM-010
A tipping point is a context-specific threshold after which a local network
becomes more self-sustaining; it is not one universal user count.

### CSP-CLM-011
Network effects can strengthen acquisition through participant-driven loops,
but paid or viral growth is not itself proof of increasing network value.

### CSP-CLM-012
Network density can strengthen engagement and retention when participants
receive more successful, relevant interactions.

### CSP-CLM-013
Network scale can improve monetization or unit economics by increasing match
rate, liquidity, utilization, conversion, pricing, or reduced subsidy.

### CSP-CLM-014
Acquisition, engagement, and economic effects can reinforce one another but
must be observed separately before being modeled as a loop.

### CSP-CLM-015
Retention or cohort performance should be measured at the atomic-network unit,
not only as a blended global average.

### CSP-CLM-016
Subsidies and manual operations can bootstrap a network, but the path to
reduced subsidy and self-sustaining economics must be evidenced.

### CSP-CLM-017
Networks can hit ceilings through saturation, degraded quality, overcrowding,
spam, weak discovery, or exhaustion of attractive new atomic units.

### CSP-CLM-018
Larger networks are not invincible; negative network effects can weaken
acquisition, engagement, and economics.

### CSP-CLM-019
Network moats depend on switching or multi-homing friction, hard-side
retention, density, and the competitor's ability to reproduce atomic networks.

### CSP-CLM-020
Local network effects may reset across geographies, so aggregate scale can
overstate defensibility in an unseeded market.

### CSP-CLM-021
The correct valuation treatment depends on current network stage and
evidence: assumptions must be tied to density, retention, acquisition,
monetization, subsidy, saturation, and competition.

### CSP-CLM-022
Network-effect strength should be a sourced operating hypothesis with
disconfirmers, not a binary label or narrative moat premium.
